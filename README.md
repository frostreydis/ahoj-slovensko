# Ahoj, Slovensko — словацька для життя у Словаччині

**Ahoj, Slovensko** — програма вивчення словацької з нуля до B2 для україномовних і тренажер, що працює в браузері як вебдодаток (PWA): сайт на GitHub Pages, прогрес — у localStorage браузера.
Цей README написано і для людини, і для **агента (Claude Code тощо)**: тут є все, щоб доповнювати тренажер і виправляти помилки з іншої сесії.

---

## 1. Як користуватися

1. Відкрийте сайт тренажера в **Chrome** (адреса на GitHub Pages: `https://<нік>.github.io/ahoj-slovensko/`, див. розділ 9) і **встановіть його як додаток**:
   - **Android**: меню ⋮ → «Додати на головний екран» → «Установити»;
   - **комп'ютер**: значок «Установити» праворуч в адресному рядку (або в меню ⋮);
   - **iPhone / iPad**: «Поділитися» → «На екран „Додому“».
   Тренажер також підкаже це на вкладці «Сьогодні» і в ⚙️ «Налаштування». Встановлений додаток відкривається в окремому вікні й працює без інтернету, а Chrome надійніше зберігає його дані (див. нижче).
2. Словацькою говорить словацький голос:
   - **голос системи**, якщо він є: в Edge на Windows це *Microsoft Lukas / Viktoria Online (Natural)*, на Mac і iPhone — *Laura*, на Android — словацький голос Google;
   - інакше — **онлайн-голос Google** (словацький, потрібен інтернет). Так буває в Chrome на Windows і на Mac, де голос Laura ще не завантажено.
   Голос можна вибрати в ⚙️ «Налаштування» → «Голос». Там само є інструкція, як додати словацький голос у систему, щоб він працював без інтернету. Несловацьким голосом тренажер нічого не читає.
3. Почніть із вкладки «Сьогодні»: там план на день, поточний урок і таймер.
4. Прогрес зберігається в браузері на цьому пристрої. Кожен пристрій і кожен браузер має свій окремий прогрес; перенесення між ними немає (свідоме рішення: лише localStorage, без сервера й без файлів).

### Надійність збереження

- Прогрес лежить у localStorage сайту під ключем `sk-trainer-v1` і записується після кожної дії.
- **Постійне сховище.** Під час запуску тренажер просить у Chrome постійне сховище (`navigator.storage.persist()`). Тоді Chrome не видаляє дані сайту сам, навіть коли на пристрої мало місця. Chrome вирішує без запитання і зазвичай дозволяє це **встановленим додаткам**, закладкам і сайтам, якими часто користуються. Стан видно в ⚙️ «Налаштування» → «Збереження прогресу».
- **Кілька вкладок або вкладка + встановлений додаток** не затирають прогрес одне одного: зміна в одній вкладці перечитується в інших.
- **Якщо запис не вдався** (немає місця, заблоковано дані сайтів), з'являється попередження, а подробиці — в налаштуваннях.
- **Прогрес зникне**, якщо в Chrome очистити «Файли cookie та інші дані сайтів» для цього сайту. У режимі інкогніто прогрес живе лише до закриття вікна. Посилання, відкрите у вбудованому браузері Telegram чи іншого застосунку, має окреме сховище — відкривайте тренажер у Chrome або як встановлений додаток.
- **Офлайн і оновлення.** Після першого відкриття тренажер працює без інтернету (крім онлайн-голосу). Нову версію уроків браузер бере з мережі під час наступного відкриття; у вже відкритому вікні з'явиться «🔄 Вийшла нова версія → Оновити». Прогрес оновлення не зачіпає.

### Прогрес, пропуски і «почати наново»

- **Що зберігається:** стан кожного уроку (теорія, вправи ≥ 80%, розмова, місія), **незавершений підхід до вправ** (можна закрити й продовжити з того самого завдання — наприклад, половину вправ у вівторок, решту в четвер), пропущені уроки, повторення слів, «Мої слова», позначки модулів A2–B2, дні занять і серія. Підсумок — у ⚙️ «Налаштування» → «Збереження прогресу».
- **Пропустити завдання:** кнопка «Пропустити ⏭» показує правильну відповідь і переходить далі. Пропущене завдання рахується як невиконане, тож урок може не зарахуватися.
- **Пропустити урок:** у шапці уроку кнопка «⏭ Пропустити урок» (тему вже знаю; на телефоні — у «⋯ Керування уроком»). Головна сторінка переходить до наступного уроку. «↩ Повернути урок» скасовує пропуск.
- **Почати з певного уроку:** «▶ Почати з цього уроку» позначає всі попередні незавершені уроки як пропущені.
- **Пройти урок наново:** «↺ Пройти урок наново» скидає позначки і вправи уроку; слова лишаються в повторенні.
- **Почати все спочатку:** ⚙️ «Налаштування» → «Скинути уроки», «Скинути повторення слів» або «Почати навчання з нуля» (налаштування голосу зберігаються). Скидання не можна скасувати.
- Будь-який урок, вкладку чи тренажер можна відкрити в будь-який момент — нічого не заблоковано.

```
├─ validate.mjs            ← перевіряє дані уроків
├─ tools/
│  ├─ icons.mjs            ← малює PNG-іконки з прапора в src/index.html (без залежностей)
│  └─ selftest-console.js  ← самоперевірка в браузері (вставити в консоль F12)

├─ LICENSE-CONTENT.md      ← CC BY-NC-SA 4.0 — для навчальних матеріалів

└─ src/
   ├─ index.html           ← каркас; підключає CSS і JS (порядок важливий); прапор у шапці — джерело іконок
   ├─ manifest.webmanifest ← опис вебдодатка (назва, кольори, іконки)
   ├─ sw.js                ← шаблон service worker (build.mjs підставляє версію й список файлів)
   ├─ styles.css           ← стилі (світла й темна теми, мобільна нижня навігація, друк)
   ├─ core.js              ← стан і localStorage (міграції, синхронізація вкладок, постійне сховище, встановлення), дати й серія днів, озвучення (голос системи або онлайн-голос Google), запис голосу, перевірка відповідей, інтервальне повторення
   ├─ gen.js               ← генератор вправ на числа, ціни, час і дати (числа словами, «о котрій», дати в родовому); без DOM
   ├─ exercises.js         ← рушій вправ (типи c / i / o / l / g) і клавіатура з діакритикою
   ├─ views.js             ← екрани «Сьогодні», «Програма», «Уроки», «Урок»
   ├─ views2.js            ← екрани «Слова», «Тренажер чисел» (#/drill), «Розмова», «Довідник», «Налаштування», маршрутизація, реєстрація service worker, init
   └─ data/
      ├─ lessons-a0.js     ← етап 0 (уроки 0.1–0.5)
      ├─ lessons-a1a.js    ← A1.1–A1.6
      ├─ lessons-a1b.js    ← A1.7–A1.13 (разом з A1.8b «Числа, дати, пори року й кольори»)
      ├─ program.js        ← програма: принципи, тижневий ритм, етапи, модулі A2–B2
      ├─ reference.js      ← довідник: вимова, фальшиві друзі, відмінки, зразки відмінювання, займенники, дієслова

```

Технології: чистий JavaScript без залежностей і без фреймворків. Маршрутизація — через `#/...`. Глобальний простір імен — `window.SK`.
Тренажер працює лише через `https://` (GitHub Pages) або `http://127.0.0.1` / `localhost` під час розробки: service worker і мікрофон потребують безпечного контексту. Відкриття з `file://` не підтримується.
Service worker реєструється лише в зібраній версії (`docs/`, де є `SK.BUILD`). У `src/` його немає, тож правки видно одразу, без кешу.

## 4. Робочий цикл агента (обов'язково)

1. **Редагуйте тільки `src/`** (і за потреби `tools/`, `build.mjs`, `validate.mjs`). Папка `docs/` генерується, але її теж комітять: GitHub Pages віддає сайт саме з неї.
2. Після змін виконайте:
   ```
   node validate.mjs    # дані уроків: структура, дублікати, [[ ]], посилання модулів на уроки
   node build.mjs       # збирає docs/ (index.html, sw.js, manifest, іконки) і друкує версію збірки
   ```
   Для коду ще: `node --check src/<файл>.js`.
3. Перевірте в браузері: `python -m http.server 8000 -d docs` і відкрийте `http://127.0.0.1:8000/` у Chrome, F12 → Console, вставте вміст `tools/selftest-console.js`. Очікуваний результат — «✅ Усе гаразд». Прогрес на цій адресі скрипт відновлює сам. Для розробки без кешу можна відкрити `src/` так само: `python -m http.server 8000 -d src`.
   Якщо зібрана версія показує старий вміст: F12 → Application → Service workers → Unregister (або «Update on reload»).
4. **Нічого не встановлюйте** (npm-пакети, бібліотеки тощо): проєкт навмисно без залежностей. Потрібні лише `node` і за бажанням `python`.
5. Додайте рядок у «Журнал змін» унизу цього файлу.

## 5. Формат уроку (`src/data/lessons-*.js`)

```js
window.SK = window.SK || {};
SK.lessons = SK.lessons || [];
SK.lessons.push({
  id: 'a2-1',               // унікальний, НЕ змінювати після публікації (від нього залежить прогрес)
  stage: 'a2',              // id етапу з program.js: a0 | a1 | a2 | b1 | b2
  num: 'A2.1',              // номер для показу
  title: 'Відмінки однини: чоловічий рід',
  dur: '2 тижні',
  goals: ['…', '…'],        // «після уроку я вмію…»
  theory: `HTML-рядок`,     // див. розмітку нижче
  vocab: [['slovo', 'переклад', 'примітка (необов\'язково)'], …],
  ex: [ …вправи… ],
  say: [['Slovenská fráza.', 'Переклад.'], …],   // фрази для shadowing (запис голосу)
  speak: ['Завдання для говоріння вголос', …],
  mission: 'Завдання в реальному житті в Словаччині'
});
```

### Розмітка в `theory`, `mission`, поясненнях `e`

- `[[текст]]` — клікабельний словацький фрагмент з озвученням; `[[показати|що озвучити]]` — якщо озвучувати треба інше.
- Звичайний HTML: `<h3>`, `<p>`, `<b>`, `<ul>`, таблиці всередині `<div class="tblwrap"><table>…</table></div>`.
- Блоки-виноски: `<div class="tip">` (порада), `<div class="note">` (пастка / увага), `<div class="good">` (добра новина / подібність з українською).
- Не вживайте рядок `</script` — збирання впаде.

### Типи вправ (`ex`)

| `t` | Що це | Поля | Правила |
|---|---|---|---|
| `c` | вибір | `q`, `o: [правильний, хибний, хибний]`, `e?` | **`o[0]` — правильний** (порядок перемішується автоматично). Хибні варіанти мають бути *однозначно* хибними в літературній словацькій. |
| `i` | введення | `q`, `a: 'відповідь'` або `['варіант1','варіант2']`, `e?` | Регістр і розділові знаки ігноруються. Без діакритики — «майже» (зараховується, якщо в налаштуваннях не ввімкнено суворий режим). |
| `o` | порядок слів | `q` (переклад українською), `a: 'Речення.'` або масив альтернатив | Слова беруться з першого варіанта (розбивка за пробілами). Альтернативи мають складатися з тих самих слів — це перевіряє `validate.mjs`. Додавайте всі природні варіанти порядку. |
| `l` | диктант (озвучення) | `a: 'текст'`, `tr: 'переклад'` | Текст озвучує словацький голос, користувач його записує. |

| `g` | генерована вправа | `g: 'назва'`, `min?`, `max?` | Під час запуску `gen.js` перетворює її на `l` або `i` з новими випадковими даними. Генератори: `numListen` (число на слух → цифрами), `priceListen` (ціна), `timeListen` («о котрій»), `dateListen` (дата), `numWords` (число → словами), `timeWords`, `dateWords`. |

`e` — пояснення після відповіді (з розміткою `[[ ]]`).

Згенеровані вправи можуть мати службові поля (це не для ручних даних): `say` (що озвучити замість `a`), `check(v)` (власна перевірка, яка повертає `'ok'`/`'bad'`), `nospace` (пробіли не важливі), `nodia` (без клавіатури з діакритикою), `ph` (підказка в полі), `h` (заголовок диктанту).
Новий генератор додається в `G` у `gen.js`. Його відповідь має проходити власну перевірку (`validate.mjs` проганяє кожен генератор 300 разів), а сам генератор треба додати в `DRILLS` у `views2.js`, якщо він потрібен у тренажері чисел.

### Модель стану (localStorage, ключ `sk-trainer-v1`)

```js
SK.S = {
  v: 1,                                                 // версія схеми стану (core.js → VERSION)
  settings: { voice, rate, strict, newPerDay, dir },   // voice: '' — автоматично, '@online' — онлайн-голос Google, інакше ім'я голосу системи
  lessons: { '<id уроку>': { opened, theory, ex: { best, done }, speak, mission, skipped,
                             run: { n, q: [[індекс вправи, повтор?], …], pos, ft: {індекс: правильно?}, sk: {індекс: пропущено} } } },
  modules: { '<id модуля>': true },          // ручні позначки A2–B2
  cards:   { '<lessonId|слово>': { due, int, ease, reps, lapses } },
  custom:  [{ sk, uk }],  days: { '<номер дня>': { ex, cards, speak } },  newDay: { day, count },
  ui:      { installTip }                    // false — учень сховав пораду «встановіть як додаток»
}
```

- Під час читання (`core.js` → `load`) стан проходить `migrate` (кроки `MIGRATIONS`), зливається з `DEFAULTS` (нові поля отримують значення за замовчуванням, ключі `__proto__` / `constructor` / `prototype` відкидаються) і `tidy` (налаштування приводяться до чисел і відомих значень).
- Якщо збережений запис не вдалося розібрати, його копія лишається під ключем `sk-trainer-v1-broken`, а тренажер стартує з чистого стану. Якщо запис зроблено новішою версією (`v` більше за `VERSION`), тренажер нічого не записує, доки сторінку не оновлять.
- Стан сховища — `SK.store` (`newer`, `broken`, `failed`), постійне сховище — `SK.Storage.persisted`, встановлення — `SK.Install`, `SK.isInstalled()`.
- Урок «закритий» (`SK.lessonClosed`), якщо пройдений (`ex.done`) або пропущений (`skipped`). Поточний урок — перший не закритий (`SK.currentLesson`).
- Функції керування — у `core.js`: `skipLesson`, `resetLesson`, `startFrom`, `resetLessons`, `resetWords`, `resetState`.
- `run` зберігається, лише поки підхід не завершено. Якщо кількість вправ уроку змінилася (`run.n`), збережений підхід ігнорується.

### Сумісність прогресу — важливо

- **Не перейменовуйте** `id` уроків: від них залежить, чи урок пройдено.
- Ідентифікатор картки слова — `lessonId|словацьке_слово`. Якщо змінити текст `vocab[i][0]`, прогрес повторення цього слова скинеться. Виправляти помилки можна й треба — просто майте це на увазі.
- `id` модулів у `program.js` теж не змінюйте: на них тримаються ручні позначки «виконано».
- **Ключ сховища `sk-trainer-v1` не змінюйте** (навіть коли змінюється формат стану): інакше збережений прогрес не відкриється.
- Змінюєте формат стану (перейменування, перенесення чи зміна змісту поля) — підніміть `VERSION` у `core.js` і додайте крок `MIGRATIONS[стара_версія] = (s) => { … }`, який переводить старі дані в новий формат. Нові поля з розумним значенням за замовчуванням міграції не потребують — досить додати їх у `DEFAULTS`.

## 6. Як додати урок для модуля A2 / B1 / B2

| Що не так | Де шукати |

| Помилка в словацькому слові, перекладі, правилі | `src/data/lessons-*.js` або `reference.js` |

| Інтервали повторення слів | `core.js` → `SK.srsGrade`, `SK.srsQueue` |
| Пропуск, продовження підходу, «пройти наново» | `exercises.js` → `run`/`save`/`record`; `core.js` → `skipLesson`, `resetLesson`, `startFrom`; кнопки — `views.js` → `lessonControls` |

| Прогрес не зберігається, зник або «двоїться» між вкладками | `core.js` → `load`, `SK.save`, `SK.store`, подія `storage`; перемальовування — `views2.js` → `SK.onExternalChange`. ## 9. Публікація на GitHub Pages

1. Репозиторій — **публічний** (безкоштовний GitHub Pages працює лише з публічних репозиторіїв). Перед першим комітом увімкніть приховування пошти: GitHub → Settings → Emails → «Keep my email addresses private» і в цій папці виконайте `git config user.email "<id>+<нік>@users.noreply.github.com"` (адресу показує та сама сторінка). Інакше ваша пошта буде видна в історії комітів.
2. Створіть публічний репозиторій **`ahoj-slovensko`** (опис, наприклад: «Тренажер словацької для україномовних: з нуля до B2, офлайн, PWA»; теги `slovak`, `ukrainian`, `language-learning`, `pwa`). Закомітьте все разом із `docs/` і відправте в гілку `main`. Назву репозиторію після публікації краще не змінювати: зміниться адреса сайту, а GitHub Pages зі старої адреси не перенаправляє.
3. GitHub → репозиторій → Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/docs** → Save. Через хвилину-дві сайт буде на `https://<нік>.github.io/ahoj-slovensko/` (HTTPS вмикається автоматично).
4. Кожне оновлення: правки в `src/` → `node validate.mjs` → `node build.mjs` → самоперевірка → коміт `src/` **і** `docs/` → push. Телефони отримають нову версію під час наступного відкриття з інтернетом.

Що варто знати:
- Усі сайти GitHub Pages одного акаунта (`https://<нік>.github.io/…`) мають **спільний localStorage**. Ключ тренажера `sk-trainer-v1` унікальний, але не розміщуйте під тим самим акаунтом чужі сторінки, яким не довіряєте.
- Онлайн-голос — неофіційний сервіс Google (`translate_tts`), без ключа й без гарантій: його можуть змінити чи обмежити. Запити йдуть із браузера учня, і йому надсилається лише словацький текст для озвучення.
- У репозиторії немає секретів і особистих даних; прогрес учнів у репозиторій не потрапляє.
